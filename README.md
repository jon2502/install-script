# linux installation program

## Made with
- bash

## project details
The purpose of this program is to automate the setup of a new Linux machine by installing and configuring all the software and tools I need.

## how to run
1. open a command terminal in the folder
2. run the setup script 

## setup script
```bash
bash setup.sh
```

## Notes
1. this program was made for Linux Mint so if you wannt to use it for another Linux distro chnages will have to be made to the program
2. Node.js and .NET both install specific versions. Check whether your system supports those versions, or if you can use a newer version instead.
